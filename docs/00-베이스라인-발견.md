# 00. 베이스라인에서 나온 발견

에이전트를 한 줄도 쓰기 전에, 픽스처를 이관하고 테스트를 돌리는 것만으로 결함 3건이 나왔다.
이 레포의 논지가 우연히 첫날 증명된 셈이라 기록해 둔다.

측정 시점 기준: `28 passed (28)`, 커버리지 **97.61% stmts / 93.05% branch**.

---

## 발견 1 — 테스트 순서에 의존해 실패한다 (수정함)

`src/pages/entry/test/OrderEntry.test.tsx`

```js
server.resetHandlers(
    http.get(`${URL}/scoops`, () => new HttpResponse(null, { status: 500 })),
    // ...
)
```

msw에서 `resetHandlers()`는 인자가 없으면 초기 핸들러로 되돌리지만,
**인자를 주면 초기 핸들러 목록 자체를 넘긴 것으로 교체한다.**

그래서 이 파일 첫 번째 테스트가 500 핸들러를 영구히 심어버리고,
`setupVitest.ts`의 `afterEach(() => server.resetHandlers())`는 이제 500 핸들러로 리셋한다.
두 번째 테스트는 스쿱 목록을 못 받아 에러 배너만 뜨고 실패한다.

증상이 고약한 이유:

| 실행 방식 | 결과 |
|---|---|
| `vitest -t "disable order button"` (단독) | ✅ 통과 |
| `vitest run` (전체) | ❌ 실패 |

테스트 범위 오버라이드는 `server.use()`가 맞다. 한 줄 교체로 해결.

## 발견 2 — 환경변수가 항상 `undefined`다 (보존)

7개 파일이 이렇게 읽는다.

```js
const URL = import.meta.env.API_URL;
```

Vite는 **`VITE_` 접두사가 붙은 변수만** 클라이언트에 노출한다.
게다가 `.env` 파일 자체가 레포에 없다. 즉 `URL`은 어떤 경우에도 `undefined`다.

그런데 테스트는 통과한다. msw 핸들러도 같은 `undefined`를 써서
`undefined/scoops`로 등록하고, 컴포넌트도 `undefined/scoops`로 요청하니
**양쪽이 똑같이 틀려서 서로 맞는다.**

목킹이 소스와 같은 상수를 공유하면, 그 상수가 틀려도 테스트는 못 잡는다.

## 발견 3 — 이미지가 한 장도 뜨지 않는다 (보존)

`src/app/apiMockHandler.ts`가 내려주는 필드명이 `immagePath`(m 두 개)다.

```js
{ name: 'Chocolate', immagePath: '/images/chocolate.png' }
```

컴포넌트는 `imagePath`로 구조분해한다. 항상 `undefined`.
발견 2와 겹쳐서 최종 `src`는 이렇게 된다.

```html
<img src="undefined/undefined" alt="Chocolate scoop" />
```

이걸 검증해야 할 테스트의 이름이 하필 이렇다.

```js
test('displays image for each scoop option from server', async () => {
    const scoopImages = await screen.findAllByRole('img', { name: /scoop$/i });
    expect(scoopImages).toHaveLength(2);          // 개수만 본다
    expect(altText).toEqual([...]);                // alt만 본다
});                                                // src는 아무도 안 본다
```

`img` 커버리지는 100%다. 이미지는 안 뜬다.

## 발견 2·3을 일부러 안 고친 이유

이 레포가 하려는 주장이 **"커버리지는 테스트의 강도를 말해주지 않는다"**인데,
그 주장의 실물 증거를 첫날 주웠다. 지금 고치면 증거가 사라진다.

그래서 두 건은 픽스처에 그대로 둔다. 나중에 뮤테이션 테스팅을 붙이고
에이전트에게 테스트를 다시 쓰게 했을 때, **이 두 건을 잡아내는지**가
그 자체로 평가 지표가 된다.

발견 1만 고친 건 성격이 달라서다. 그건 결함이 아니라 **불안정성**이고,
전체 실행이 빨간불이면 베이스라인 측정 자체가 안 된다.
